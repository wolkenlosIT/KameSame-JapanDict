# KameSame-JapanDict
Maybe you are like me and use KameSame for learning Japanese. One thing that I missed, was JapanDict.com. It is my favorite Jisho, because it contains german (and other languages) too, which is very helpful, because the english translations are sometimes to vague. This Tampermonkey script adds JapanDict to KameSame as the first external link in all modes on KameSame:
![BeispielKameSame](https://github.com/wolkenlosIT/KameSame-JapanDict/blob/main/example.jpg)


## Requirements
* Tampermonkey

## Installation
1. Open the Tampermonkey Dashboard
2. Click on the little + to add a new script
3. Copy and paste the script into the editor
4. Safe
5. Reload KameSame
